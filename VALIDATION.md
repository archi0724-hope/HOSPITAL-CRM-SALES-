## Limits

Browser download-event capture timed out for the generated blob, so browser end-to-end download delivery was not confirmed through automation. The export button produced no application console exception and the exact workbook generator passed independent openpyxl readback. Users may need to allow browser downloads.

Every add/edit variant, image format, browser, print driver and quota condition was not exhaustively tested. No live API, payment gateway, reminder, email, WhatsApp or database behavior is available or tested. Mobile testing used an iframe viewport, not a physical phone. Some unrelated browser-extension metadata errors appeared during rapid navigation; application-origin errors were not observed in the tested flows.

The frontend approximates secondary screens and does not constitute a certified production CRM. See INSPECTION.md for source-review limits and API_REQUIREMENTS.md for server responsibilities.
